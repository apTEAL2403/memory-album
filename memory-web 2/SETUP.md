# メモリーアルバム — セットアップガイド（v2）

```
メインページ（コミュニティ選択）
├── 家族ページ   合言葉: TEAL
├── 親友ページ   合言葉: 0901
└── 彼氏ページ   合言葉: Masaoi
```

「デート」「テーマ」という区切りはなくなり、各ページとも
**年月日順に並ぶ1本のギャラリー**になっています。
テーマの代わりに、写真の合間に自由な「文言」を挟めます。
デザインは5種類のテンプレート（星／映画／野原／ホーム／タオル）から
いつでも好きな気分のものに切り替えられます。

以前このアプリをセットアップ済みの方も、**手順2だけやり直せば**
新しい構造に移行できます（データベースの表が変わったため）。

---

## 1. Supabaseのアカウントとプロジェクト（初めての方のみ）

1. https://supabase.com で無料アカウントを作成
2. 「New Project」でプロジェクトを作成（リージョンは Tokyo がおすすめ）
3. 左メニュー **Project Settings → API** から
   「Project URL」と「anon public」キーをコピー

## 2. データベースの表を作る（今回の変更で必須）

1. 左メニューの **SQL Editor** を開く
2. 同梱の `schema_v2.sql` の中身を全部貼り付けて実行（RUN）
   - 以前の `themes` / `groups` の表は削除され、
     `photos`（写真）・`notes`（文言）・`playlist_tracks`（年ごとの曲）
     の3つに作り直されます
   - `comments`（写真へのコメント）はそのまま引き継がれます

## 3. 画像・動画・音楽の保存場所（初めての方のみ）

1. 左メニューの **Storage** で `media` という名前のバケットを作成
2. 作成時に **Public bucket** を必ずON

## 4. 認証情報の設定（初めての方のみ）

`shared/supabase-config.js` の2箇所を、手順1でコピーした
URLとanonキーに書き換えて保存してください。

## 5. 公開する（おすすめ: GitHub Pages）

1. GitHubのリポジトリにこのフォルダの中身をアップロード
2. **Settings → Pages** で公開をON
3. 発行されたURLの後ろに `family/`・`friend/`・`boyfriend/` を
   付けてそれぞれのページへ

## 使い方

### 写真を追加する（右下の＋ → 「写真を追加」）

年月日を入力してアップロードすると、その日付の位置に
自動的に並びます。複数枚まとめて選ぶこともできます。

### 文言を挟む（右下の＋ → 「文言」）

写真の合間に挟みたい説明文を、日付を指定して追加できます。
一度追加した文言は、**ギャラリー上の「✎ 編集」ボタン**から
誰でも・どの端末からでも書き直せます（削除は管理パネルから）。

### 年ごとのプレイリスト（右下の＋ → 「プレイリスト」）

年を指定して曲をアップロードすると、その年のプレイリストに
追加されます。表示する年のタブを切り替えると、その年の
プレイリストがランダムな順番で自動的に流れ始めます。
右上の♪ボタンで再生・停止を切り替えられます。

### 写真へのコメント

各写真の下にある「💬 コメントを見る・残す」から、コメントの
閲覧・投稿ができます。書き込んだ内容はデータベースに保存されるため、
**別の端末・別のブラウザで開いても同じコメントが表示されます**。
見た目がにぎやかになりすぎないよう、普段は折りたたまれています。

### デザインテンプレートを変える

右上の🎨ボタンから、いつでも5種類のデザインに切り替えられます。
選んだデザインはブラウザに記憶され、次に開いたときも同じものが
表示されます（3つのページどこからでも切り替え可能です）。

- ⭐ **星**：黒〜濃紫のグラデーションと瞬く星
- 🎬 **映画**：ワインレッドとレトロなフィルムの質感
- 🌾 **野原**：青空・電線・そよ風にそよぐ草花と自転車
- 🏠 **ホーム**：木のあたたかさと白い壁の明るい家庭的な雰囲気
- 🧺 **タオル**：もこもこ・ふわふわで落ち着く質感

### 合言葉について、正直なお知らせ

この合言葉は「知らない人が偶然たどり着かないための簡易的な鍵」であり、
本格的なログインのような強固なセキュリティではありません。
URLを本人以外に教えない前提での運用をおすすめします。

## よくある詰まりどころ

- 写真が表示されない → Storageのバケットが「Public」になっているか確認
- コメント・文言が保存されない → `schema_v2.sql` を実行し忘れていないか確認
- 曲が自動再生されない → ブラウザの仕様上、ページを開いた直後は
  自動再生できないことがあります。年タブをクリックすると再生されます
- 何も表示されない・真っ白 → `supabase-config.js` のURL/キーが
  正しく貼り付けられているか確認（ブラウザの開発者ツールでエラーが見えます）
